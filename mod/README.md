# ShopVisuals (Fabric 1.21.1)

Watermark, animated module list, keystrokes (+CPS), coords/speed. Right Shift opens the GUI
(rebindable in Controls). Settings are saved to `config/shopvisuals.json`.

Build: open in IntelliJ IDEA (Java 21) and run the `build` Gradle task, or run `gradle wrapper`
then `./gradlew build`. The jar appears in `build/libs/`. Requires Fabric API.
